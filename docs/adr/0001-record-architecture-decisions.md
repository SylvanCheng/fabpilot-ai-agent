# ADR-0001: Record architecture decisions

- Status: Accepted
- Date: 2026-11-02

## Context
FabPilot is built by one developer over several months and is meant to be a reusable template
for future products. Decisions made now will be questioned later, by the author or by reviewers.

## Decision
Record each significant decision as an ADR in `docs/adr/`, numbered, immutable once accepted.

## Consequences
A few minutes of writing per decision; in return, reasons survive and reversals are deliberate.
