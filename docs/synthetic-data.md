# Synthetic fab data

Generated by `fabpilot-datagen` (`backend/src/fabpilot/datagen/`). Deterministic for a given
`--seed`; the simulation window ends at a fixed time (2026-10-31 UTC) so results are reproducible.
All names are invented; nothing is derived from a real fab.

## Model

- 2 products (`PRD-A` logic-like, `PRD-B` power-like), one 25-step route each
  (clean → oxidation → STI → implant → gate → poly → contacts → M1 → passivation).
- 27 tools across 11 equipment types (`ETCH-01..04`, `CMP-01..02`, …).
- Lots of 25 wafers start uniformly over 60 days; each step has queue + process time;
  lots still running at the end are `WIP`.
- Inline metrology on 5 sampled wafers × 5 sites for `PAD_OX_THK`, `STI_STEP_HEIGHT`, `POLY_CD`,
  `ILD_THK`. Each value = target + tool offset (of the tool that ran the *source* step) +
  wafer bias + noise.
- Out-of-spec lot means create an `OOS` hold.
- Finished lots get wafer sort yield, with WM-811K-style map-pattern labels.
- Equipment events: background alarms and one PM per tool.

Default size: 120 lots, 3,000 wafers, ~12k measurements.

## Injected scenarios (ground truth for tools & evals)

Do **not** expose this file to the agent; it is the answer key.

| Scenario | What happens | Where it shows up |
|---|---|---|
| `etch_drift` | `ETCH-03` drifts from 21 days before end. `POLY_CD` on lots etched there rises linearly up to +7 nm (USL = 60 nm). | `measurement` (POLY_CD by etch tool and time), `defect_inspection` at POLY DEFECT INSP, `wafer_yield` drop with `Edge-Ring` pattern, `RF_REFLECTED_PWR_HIGH` alarms on ETCH-03, `OOS` holds late in the window |
| `cmp_post_pm` | `CMP-02` has a PM 12 days before end. The next 4 lots through ILD CMP on `CMP-02` come out 25–40 nm thin. | `measurement` (ILD_THK), `equipment_event` PM_START/PM_END on CMP-02, small yield loss |

Example check (as `fab_reader`):

```sql
SELECT h.equipment_id, date_trunc('week', h.track_in)::date AS week, round(avg(m.value)::numeric, 2) AS poly_cd
FROM measurement m
JOIN wafer w USING (wafer_id)
JOIN lot_step_history h ON h.lot_id = w.lot_id
JOIN process_step s ON s.step_id = h.step_id AND s.step_name = 'POLY ETCH'
WHERE m.param_name = 'POLY_CD'
GROUP BY 1, 2 ORDER BY 2, 1;
```
